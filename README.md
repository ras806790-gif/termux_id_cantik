## 📌 Tentang

**ID Cantik Generator** adalah tools profesional buatan **RASYA** yang dirancang untuk menggenerasi dan membuat kombinasi ID freefire unik serta menarik di Termux.  
Dilengkapi dengan menggunakan **Supabase** sebagai database backend.

---

### ✨ Fitur Unggulan

| Fitur | Deskripsi |
|-------|-----------|
| 🎯 **Auto Generator** | Pembuat kombinasi ID cantik & unik otomatis |
| 📱 **Multi-Platform** | Kompatibel penuh dengan Android (Termux) |
| ⚡ **Multi-Threading** | Proses generasi cepat dengan dukungan 1-10 thread |
| 🔄 **Auto Update** | Cek update & ketersediaan fitur terbaru |
| 🛡️ **Aman** | Source code terenkripsi untuk keamanan pengguna |
| 📊 **Admin Panel** | Manajemen pengguna & lisensi secara lengkap |

## 🛠️ Instalasi

### 📱 Termux (Android)

```bash
# 1. Update & upgrade
pkg update && pkg upgrade -y

# 2. Setup penyimpanan
termux-setup-storage

# 3. Install Python & Git
pkg install python git -y

# 4. Clone repository
git clone [https://github.com/ras806790-gif/termux_id_cantik.git](https://github.com/ras806790-gif/termux_id_cantik.git)

# 5. Masuk ke direktori
cd termux_id_cantik

# 6. Install dependencies
pip install -r requirements.txt

# 7. Jalankan
python gen.py
